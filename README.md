# Netflix Landing Page 🎬

A responsive and visually appealing clone of the Netflix landing page, built using HTML, CSS, and a touch of JavaScript. This project aims to replicate the UI of Netflix's homepage to practice front-end web development skills.

## 🚀 Features

- 🎨 Netflix-inspired UI
- 📱 Fully responsive design
- 🌙 Dark theme layout
- 🧭 Smooth navigation bar
- 🖼️ Hero banner with call-to-action
- ✉️ Simple email subscription form
